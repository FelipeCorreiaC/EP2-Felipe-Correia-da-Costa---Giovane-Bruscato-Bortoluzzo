# EP1-Felipe-Correia-da-Costa---Giovane-Bruscato-Bortoluzzo
Projeto desenvolvido por Felipe Correia e Giovane Bruscato para praticar habilidades de programação por meio da criação do jogo Batalha Naval, no qual os jogadores posicionam estrategicamente seus navios e tentam afundar a frota adversária.


# TUTORIAL DE COMANDOS DO VSCODE/GITHUB
Receber atualizações = git pull
Preparar arquivos = git add .
Registrar alterações = git commit -m "Descrição das alterações"
Enviar ao GitHub = git push

## Comandos adicionais

Verificar o estado dos arquivos = git status
Visualizar o histórico de commits = git log --oneline
